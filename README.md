### Olá, eu sou o Rafael

Analista de Dados Sr em Manaus/AM, trabalhando com BI para Controladoria e indústria. Comecei em 2018 na produção de uma indústria de injeção plástica e passei pelo administrativo, pela ordem de produção e pela Controladoria antes de assumir a área de dados. Por isso, discuto o número tanto com quem opera o processo quanto com quem lê o relatório.

Hoje estruturo a área de dados da empresa: modelos em esquema estrela sobre o SAP Business One, indicadores em DAX e regras de negócio documentadas para custo, estoque, margem e produção.

**O que faço**

- Modelagem dimensional e medidas DAX, com os modelos versionados como código (PBIP/TMDL)
- Integração de fontes: SAP HANA, SQL Server, PostgreSQL, MySQL e APIs REST
- ETL e automação em Python, Power Query e Power Automate, com execução no Azure
- Conciliação de indicador com a fonte oficial antes de publicar
